 Event Registration & Ticketing System

A serverless REST API for event registration and ticketing, built on AWS.
Replaces manual Microsoft Forms + Excel tracking with a scalable, automated system.

## Architecture
- **API Gateway** — REST endpoints
- **AWS Lambda** — business logic
- **DynamoDB** — Events & Registrations storage
- **CloudWatch** — logging and alarms
- **SNS** (optional) — confirmation emails
- **AWS Budgets** — cost tracking (Free Tier)
- **Terraform** — infrastructure as code
- **GitHub Actions** — CI/CD pipeline
